# LES GRANDES MAISONS — liste de référence de JJ (phase 1)
#
# Liste arrêtée par Victor : les 100 maisons de départ, plus celles ajoutées
# depuis. Elle décide de ce qui apparaît sur le site : une
# offre chez un employeur absent d'ici est écartée par le pipeline.
#
# Format :   Nom affiché | motif de reconnaissance (expression régulière)
#
# Le motif est comparé au nom d'employeur renvoyé par les sources, qui écrivent
# la même maison de dix façons ("BNP PARIBAS", "Bnp Paribas Mission Handicap").
# Il est testé sans accent ni casse, et ancré au DÉBUT du nom — sauf si le motif
# commence par ".*". Le premier motif qui correspond gagne : l'ordre compte, on
# place donc "Crédit Agricole CIB" avant "Crédit Agricole".
#
# Une maison peut couvrir plusieurs entités : BPCE attrape les Caisses d'Épargne
# et les Banques Populaires régionales. La carte affiche l'entité qui recrute ;
# c'est le filtre "Entreprise" du site qui regroupe sous le nom de la maison.
#
# AJOUTER une maison : une ligne de plus, relancer le pipeline.
# PHASE 2 (ouvrir aux PME et ETI) : PHASE_GRANDES_MAISONS = false dans
# ingestion/pipeline.js. Rien d'autre à changer.
# ---------------------------------------------------------------------------
